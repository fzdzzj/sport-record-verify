## 2. 结构模型与预注册区间（不是门）

任务书预注册的结构推导：`cycle = 0.5 + T_batch/N_eff`；TASK-163 反解 `T_batch = 1.2517~1.7189s`；取 TASK-161 的 `S_prod(4)@J=0=3.1538` 作并行效率代理 ⇒ 预测 C 臂 slope 95.7~111.5、基线 45.07~57.09，比值区间 **[1.7, 2.5]**。任务书明示：该区间不是门，落在门外但 ≥1.5 仍判过；该推导依赖 TASK-161 明写「未被回答」的可迁移性假设。

**实测偏离该推导的两个原因（照实披露，不改门）**：① 今日宿主的基线斜率（A 臂 80.6~89.4）显著高于任务书引用的 45.07~57.09 先验带（宿主更快，负载期 QPS 176~245 对比 TASK-163 时代 124~204），使 C 臂需要越过的是 max(A,B)=89.40 而非先验的 ~57；② C 臂实测批内并发加速未能把 `T_batch` 压到先验假设的 1/3.15（由 C1 反解 `N_eff`：121.9729 = 100/(0.5+0.6185/N_eff) ⇒ N_eff ≈ 1.93，并行效率远低于 3.15 代理）。

## 6. 噪声与估计量方差披露（未定支的核心内容）

- **采样粒度**：排空窗内每 ~2s 一采，单轮仅 6~12 个样本；P_peak 的采样命中时机对 slope 影响显著（负载期 QPS 176~245、墙钟 8~11s，PENDING 峰值平台很短）。
