# 验收证据：规则灰度发布冒烟

来源：`scripts/smoke/smoke-*.sh` 全链路冒烟的一次实跑（记录于 2026-09-12），
原始中间产物在 `logs/`（已 gitignore）。复现方式见 [scripts/smoke/README.md](../scripts/smoke/README.md)。

口径：同一 5.8 m/s 匀速轨迹（基线 r1.speed=5.5 应拒、灰度快照 r1.speed=6.6 应过）；
verdict 取值 1=PASSED、2=REJECTED；userId%100 采样路由灰度。

## 用例结果

| 用例 | 断言 | 结果 | 关键输出 |
| --- | --- | --- | --- |
| A1 调灰度 10 触发广播 | Redis 订阅 `verify:rules:invalidate` 应收到失效消息 | 捕获到频道与消息 | `subscribe / verify:rules:invalidate / 1`（`logs/smoke-redis-sub.txt`） |
| B1 灰度命中用户 105（105%100=5<10） | 走快照 6.6，应 PASSED=1 | 一致 | `hit=19497 verdict=1 expect=1` |
| B2 灰度未命中用户 150（50≥10） | 走基线 5.5，应 REJECTED=2 | 一致 | `miss=19498 verdict=2 expect=2` |
| C1 回滚 gray=0 立即生效 | 再次提交 105 应回归基线 REJECTED=2，且触发广播 | 一致 | `rollback=19499 verdict=2 expect=2`；订阅捕获消息 `1`（`logs/smoke-redis-sub2.txt`） |
| D1 全量发布 activate | 再提交 150 应走新基线 6.6 得 PASSED=1 | 一致 | `full=19500 verdict=1 expect=1` |
| E1 广播链路（verify 侧） | 每次变更应发送广播且本地监听清缓存 | 实跑日志命中 | 「规则缓存失效广播已发送：versionId=1」「收到规则缓存失效广播，本地路由缓存已清：versionId=1」（`logs/smoke-verify.log`） |

`logs/smoke-verdicts.txt` 汇总：四条记录 `19497/19498/19499/19500` 判定与预期逐条一致。

## 补充说明

- 负向用例（N1-N4：对 ACTIVE 调灰度→4003、重复版本号→4004、比例越界→4004、不存在版本→4002）
  由 `scripts/smoke/smoke-negative.sh` 逐条打印响应，可随冒烟复跑取证。
- 库表终态（`rule_version` 终态、`verification_result`/`sport_record` 判定落库）由
  `scripts/smoke/smoke-evidence.sh` 抽取，与 verdicts.txt 相互印证。
