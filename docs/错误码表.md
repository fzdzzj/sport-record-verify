# 错误码表

> 全项目统一错误码清单：来源 `com.sportverify.common.result.ResultCode` 枚举 + 各服务 `new BizException(...)` 使用点。
> 通用约定：所有 JSON 接口统一返回 `{code, message, data}`（审批版 §4.8）；**业务错误码由响应体 `code` 承载，HTTP 状态统一 200**，例外见「HTTP 状态映射」节。

## HTTP 状态映射

| 场景 | HTTP 状态 | 响应体 code | 说明 |
| --- | --- | --- | --- |
| 成功 | 200 | 0 | |
| 业务异常（BizException） | 200 | 业务码 | 错误码放 body，不占用 HTTP 状态 |
| 认证失败（1001） | 401 | 1001 | 网关拦截（缺失/无效 token）与各控制器局部 `@ExceptionHandler` 映射 |
| 越权访问（1002） | 403 | 1002 | 各控制器局部 `@ExceptionHandler` 映射 |
| 参数校验失败（@Valid / @RequestParam） | 400 | 400 | GlobalExceptionHandler，message 含字段名与提示 |
| 畸形 JSON / 请求体不可读 | 400 | 400 | HttpMessageNotReadableException |
| 路径/查询参数类型不匹配 | 400 | 400 | MethodArgumentTypeMismatchException |
| 缺少必填查询参数 | 400 | 400 | MissingServletRequestParameterException |
| 非法参数（业务侧主动校验） | 400 | 400 | IllegalArgumentException |
| 接口不存在 | 404 | 404 | NoHandlerFoundException（需开启 throw-exception-if-no-handler-found） |
| 请求方法不支持 | 405 | 405 | HttpRequestMethodNotSupportedException |
| 未预期异常 | 500 | 9999 | 兜底，不泄漏堆栈细节 |

## 错误码总表

### 1xx 认证/授权

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 1001 | token 无效或过期 | 网关拦截缺失/无效 Bearer token；登录密码错误（AuthService:139/146）；refresh token 无效/过期/已作废（AuthService:209/217）；缺少网关注入的 X-User-Id |
| 1002 | 无权限访问 | 越权访问他人资源；账号被禁用（AuthService:142）；账号已临时锁定（AuthService:131） |

### 2xx 用户域

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 2001 | 手机号已注册 | 注册时手机号已存在（AuthService:103/117，前置查询 + 唯一键兜底） |
| 2002 | 用户不存在 | 好友操作目标用户不存在（FriendService:82）；刷新 token 对应用户不存在（AuthService:176） |

### 3xx 记录域

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 3001 | 记录不存在 | 记录/轨迹查询、申诉、终判时记录缺失（SportRecordService:159/184/216/228/245/261、VerifyService:89/218） |
| 3002 | 无权访问该记录 | 记录非本人所有（RecordController:111 等） |
| 3003 | 状态不允许该操作 | 乐观锁冲突、状态机非法迁移（SportRecordService:124/169/203、VerifyService:146/221） |
| 3004 | 幂等冲突：重复提交 | requestId 重复提交，返回原结果（SportRecordService:99） |
| 3005 | 申诉不存在 | 终判/查询不存在的申诉单（VerifyService:200） |
| 3006 | 申诉状态不允许该操作 | 非 PENDING 申诉单终判或并发状态冲突（VerifyService:203/209） |
| 3007 | 运动类型非法 | 提交接口枚举外取值（SportRecordService:280；DTO 层 @Min/@Max 已前置拦截 400） |

### 4xx 校验服务

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 4001 | 校验服务不可用 | 记录提交后调用校验引擎熔断降级（SportRecordService:193） |
| 4002 | 规则版本不存在 | 规则版本查询缺失（RuleVersionService:240） |
| 4003 | 规则版本状态不允许该操作 | 仅 GRAY 可调比例/全量发布、并发状态迁移冲突（RuleVersionService:131/138/160/164） |
| 4004 | 规则版本冲突 | 版本号重复、灰度比例越界（RuleVersionService:96/99/112/127/134） |
| 4005 | 匹配服务不可用 | mapmatch 熔断降级（MapMatchApiFallback） |
| 4006 | 用户服务不可用 | UserApi/AuthApi 熔断；好友榜读路径可空榜，认证写路径不可软降级 |
| 4007 | 记录服务不可用 | RecordApi 显式失败（不可软降级，驱动重试/DLQ） |
| 4008 | 榜单服务不可用 | LeaderboardApi 显式失败（禁止假装成功） |

### 5xx 好友域

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 5001 | 重复申请或已存在关系 | 同向 PENDING 重复申请、对方已发起申请、已是好友（FriendService:103/113/121） |
| 5002 | 关系不存在 | 好友申请/关系不存在或已处理（FriendService:152/168/197/212） |

### 6xx 点赞域

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 6001 | 记录未通过校验，不可点赞 | 对非 PASSED/RE_PASSED 记录点赞（RecordLikeService:116） |

### 系统兜底

| 错误码 | 含义 | 触发场景 |
| --- | --- | --- |
| 9999 | 系统繁忙 | 未预期异常统一兜底（GlobalExceptionHandler），仅日志记录堆栈，不对外泄漏 |

> 400/404/405 为 HTTP 契约错误码（非 BizException），由 GlobalExceptionHandler 直接映射，见「HTTP 状态映射」表。
