## 2. 实施设计（预注册）

### 2.1 提取层（`extract_claims` 重写）

- 清单小节定位沿既有 awk 节匹配（`/只改|改动|文件清单/` 起、下一标题止）；
- 小节内**逐行过滤**：仅列表行（`^\s*(-|\d+\.)\s`）进入提取；行内命中否定句式（`零触碰|未碰|未触碰|不改|禁触`）→ 整行丢弃不产 token（即使该行是列表行）；
- 删除 L124 全文回退：小节缺失 → `claims` 为空 → 走 L166-169 既有「回传未解析到改动清单，跳过判据 B」分支，并在该行输出追加「警示：无清单小节，未整档扫描」字样；
- 扩展名白名单正则原样保留（L126 不动）。

### 2.2 在途判定层（判据 B 前置门）

- 对每个 `returned_dirs` 任务，先判 `handoff.md` 基线变动：`git diff --name-only "$BASELINE" -- "$d/handoff.md"` 非空 **或** 该路径出现在 `git ls-files --others --exclude-standard` → 在途回传；两者皆无 → 输出「已收口（回传文件无基线变动），不重审」并 `continue`；
- 在途回传才做既有 both/only_claims/only_actual 比对（比对逻辑与失败输出原文保留）；
- `--diff-file` 模式：改动集来源用 `--diff-file`，在途判定仍用上述 git 双查（来源解耦）；非 git 上下文 + `--diff-file`：在途判定降级为旧共占判定（both>0 即在途），输出注明行「非 git 上下文：在途判定降级为共占口径」；
- 判据 A 循环、`--open` 解析、退出码聚合（L205-210）原文不动。
