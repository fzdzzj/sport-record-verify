# 提案：提交链路连接池容量的受控对照（含池生命周期前置修复）

## Why

TASK-140 在一轮开启诊断的 c100×2000 负载中，直接测得请求级物理连接获取 `connWait` P50 527.1ms（含池等待和可能建连，不等于纯排队）。池上限默认 10；历史「池 30」数字来自不同环境，不能直接证明在当前环境调大池有效。三轮计时关闭的同 jar 跑次又混合冷热条件，不能视为同质噪声分布。下一步只检验一个因素：`MYSQL_POOL_SIZE`。不预设 20 必然改善。

**安全前置（由当前代码静态交错推出，待红测确认）**：`TimingHikariDataSource.getConnection()` 先检查 `closed`，之后才在 `innerPool()` 内加锁懒建池；`close()` 不持同一锁，先置 `closed` 再读 `pool`。线程 A 通过检查、尚未建池时，线程 B 可关闭并读到空池返回，线程 A 随后仍能建出无人关闭的内层池。现有单线程关闭测试未覆盖该交错。必须先以确定性交错判别并最小修复；**A/B 两臂必须使用同一修复后 jar**，否则实验无效。

## What Changes

1. 补一条不依赖睡眠碰运气的并发判别测试，先对当前实现在「通过关闭检查→建池前关闭」交错下取行为红；最小修改包装类，让关闭与首次建池协调，关闭后不得建新池。两个 `getConnection` 重载及关闭幂等保留；不得持包装类生命周期锁等待 Hikari 池连接（最多 30s）。若不能可靠构造红测，记录证据不足，不编造；不得扩大至 ShardingSphere 私有实现。
2. 以修复后**同一个 jar 校验和**、相同 100 并发×2000 请求、相同 MySQL/服务/数据样本和诊断开关，仅轮换池上限 10 与 20；按 A(10)–B(20)–B(20)–A(10) 至多四次完整负载（失败也计次数）。每轮重启 record JVM，固定预热与积压排空条件；记录环境指纹、资源采样、诊断 `connWait` 与请求 QPS/P50/P95/P99/错误率。先查磁盘、容器/服务状态、MySQL `max_connections`，不足或无法维持可比条件则停止负载并写未覆盖，禁止清库或盲增连接上限。
3. 只在两次 B 与两次 A 的方向、稳定性、资源与错误共同支持时，称「此环境下候选值 20 值得进一步验证」。如分布重叠、冷热/校验队列干扰无法排除或 DB 饱和/错误升高，结论为不确定/不推荐。**本变更不修改生产默认池容量，不声称 P99、quality 或其他部署环境获益**；若真有受控证据，再另立参数落地决定。
4. 同一作业完成测试、必要报告/摘要、三件套勾选、TASK-141 台账及本地提交；不得把每条命令/单次 commit 拆成向主 agent 索取指令的多轮。未获授权不得 push/建 PR。保留原始数字与原始 raw，不覆盖 TASK-138~140 产物。

## Impact

- 规范：`spec/specs/sport-record-verify/spec.md` 的性能验证/连接池生命周期约束（本提案 spec-delta；不改提交状态机）。
- 允许代码：`record-service/src/main/java/com/sportverify/record/config/TimingHikariDataSource.java` 及 `record-service/src/test/java/com/sportverify/record/config/TimingHikariDataSourceWiringTest.java`，只改关池并发正确性；容量以已有 `MYSQL_POOL_SIZE` 环境变量切换，不改默认配置、SQL、索引、事务、JVM、MQ。
- 允许文档：新增 `docs/perf/` 本次对照报告和机器摘要；本变更三件套；TASK-141 spec/handoff 和 PLAN。原始 CSV/log 放既有忽略目录，不入库，不写真实密钥。
- API/数据库迁移：无。风险是并发关池后剩余请求的 SQLException、容量上调加重 MySQL 竞争、重复压测增长数据；分别用交错测试、错误率/资源门槛、总量与容量预算约束。诊断开启下的数字不得直接冒充默认关闭的线上性能。

## 决策与停止条件

- 行为红不能真实命中，先停修复或明确仅静态风险；修复后单测/构建失败，**不启动压测**。
- 两臂代码/配置（除池容量）不一致、服务未健康、连接上限不安全、磁盘不足、MQ 积压不可比或任一臂指标不完整，则停止并记未覆盖，不靠增加轮次凑结论。
- 四轮完成后给出「可继续验证 / 不确定 / 不推荐」之一和原始每轮结果；不宣称单次优势即因果成立，不叠加其他参数。
