## 踩坑记录

- **Windows Java stdout 编码**：OsmImporter 输出 SQL 用 `System.out`，Windows 默认 GBK，中文路名写出 GBK 字节被 psql 按 UTF8 校验拒绝（`invalid byte sequence 0xc4 0xcf`）→ 强制 `new PrintStream(FileDescriptor.out, UTF_8)`。
- **宿主机 5432 端口冲突**：本机已有 PostgreSQL 监听 5432，Java 服务连到了本地库（密码认证失败）→ 沿用仓库 MYSQL_PORT 同款方案：`.env` 加 `POSTGRES_PORT=5433`，compose 与服务侧同名变量。
- **Overpass 悬浮点定位**：城区路网极密（bbox 内无 >250m 离路网格点），黄浦江江心需沿河道走向逐点实测（min 距离 110-160m 的斜向走廊）才能构造稳定的悬浮轨迹样本。
- **Docker Hub 直连失败**：经 daocloud 镜像源拉取 `docker.m.daocloud.io/postgis/postgis:16-3.4` 后 retag 为规范名。

## 已知边界

- 路网切片范围有限（bbox 121.43-121.51 / 31.205-31.255），跨区轨迹会整段离路——生产化需全国分片/多切片路由（ADR-0006 讲设计）。
- HMM 全局匹配为进阶项（当前最近边投影对离路占比指标已足够）。
- R5 阈值走 Nacos `verify.rules.r5.*` 可配，rule_version 灰度机制天然兼容（快照编解码忽略未知字段向前兼容），灰度 UI 未单独适配。
